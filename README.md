# :diamond_shape_with_a_dot_inside: Zuko's AI Rules :diamond_shape_with_a_dot_inside:

**Repo này chứa các rules để AI agents tuân thủ khi làm việc trong các dự án của tôi.**
*Nhưng nếu thấy chúng có ích. Bạn có thể vô tư dùng nó*

Được chia làm 2 phần chính:
- Rules: Quy tắc
- Skills: Bộ kỹ năng/quy trình được đóng gói
- System prompts (Sub agents)

Hiện có những nhánh sau:

- `master`

  Chứa rules/prompts chung
- `csharp-winform`

  Rules dành riêng cho C# và WinForm
- `php-laravel`

  Rules dành riêng cho PHP và Laravel (6.x+)
- `php-laravel-filament`

  Rules dành riêng cho PHP Laravel với Filament Admin
- `python-qt`

  Rules dành riêng cho Qt và Python (PySide, PyQt)
- `rust-tauri-next`

  Rules dành riêng cho Rust Tauri với Next.js frontend
- `typescripts-cfworker`

  Rules dành riêng cho TypeScript Cloudflare Workers
