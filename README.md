# :diamond_shape_with_a_dot_inside: Zuko's AI Rules :diamond_shape_with_a_dot_inside:

**Repo này chứa các rules để AI agents tuân thủ khi làm việc trong các dự án của tôi.**

Được chia làm 2 phần chính:
- Rules
- System prompts (Sub agents)

Hiện có những nhánh sau:

- `master`

  Chứa rules/prompts chung
- `python-qt`

  Rules dành riêng cho qt và python (PySide, pyQt)
- `php-laravel`

  Rules dành riêng cho PHP và Laravel
  > Laravel phiên bản từ 6.x trở về đây*
- `csharp-winform`

  Rules dành riêng cho C# và WinForm
